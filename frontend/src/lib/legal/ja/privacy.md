## 写真の読み取り

写真で記録するとき、写真を Google LLC の Gemini API に送り、写っている血圧の値を読み取ります。

- 初めて写真を読み取る前に、送信先・送信するもの・目的をお示しして、写真を送ることへの同意をいただきます。同意は設定の画面からいつでも取り消せます。取り消した後は、次に写真で記録するときに、あらためて同意をうかがいます。
- 運営者は Gemini API を有料の条件で使っています。Gemini API の規約では、この条件で送った写真と結果を、Google は自社の製品の改善に使わず、禁止された使い方を見つけるためと法令に従うために限られた期間記録する、と定められています。
- 運営者は写真を保存しません。読み取りの間だけ、サーバーのメモリに一時的に置きます。
- 写真に血圧計以外のもの（顔や書類など）が写らないようにしてください。

## 写真の読み取りの購入

ウェブで写真の読み取りの利用枠を有料で購入するとき、決済は Stripe, Inc.（以下「Stripe」）が提供する決済ページ（Stripe Checkout）で行います。

- カード番号などの決済情報は Stripe が直接受け取り、運営者は取得・保存しません。
- 本人確認のため、メールアドレスを Stripe に渡します。
- Stripe から運営者へは、決済が完了したかどうかと、購入した商品・金額の情報が通知されます。運営者はこれをもとに、写真の読み取りの利用枠を追加します。

iPhone・iPad のアプリで購入するときは、App Store のアプリ内課金を使い、App Store を運営する Apple（日本では iTunes株式会社。以下「Apple」）が運営者に代わって代金を受け取ります。

- 支払いの情報は Apple が扱い、運営者は取得・保存しません。
- 購入をアカウントに結び付けるため、運営者がアカウントごとに作った識別子（ほかの情報を含まない乱数）を、購入の情報に添えて Apple に渡します。
- 運営者は、購入した商品・日時、返金されたかどうかなど、その購入の取引の情報を Apple から受け取ります。運営者はこれをもとに、写真の読み取りの利用枠を追加し、返金されたときは使っていない分を消します。

## 保存する期間とバックアップ

- 記録とアカウントの情報は、アカウントを削除するまで保存します。ただし、最後に利用してから12か月がたったアカウントは、自動的に削除します（下の「自動的な削除」）。
- 障害に備え、データベースを常に複製し、日ごとのスナップショットも取っています。どちらも7日分残し、それより古いものは自動で消します。
- アカウントを削除すると、30日の猶予期間ののちに、記録とアカウントの情報を消します。猶予期間のうちにログインすると、削除は取り消されます。
- LINE でログインしたことがあるアカウントは、消すときに、削除したことを LINEヤフー株式会社に通知し、本サービスと LINE の連携を解除します。このために、LINE でログインするたびに受け取るトークンを保存しています。
- Apple でログインしたことがあるアカウントも同じく、消すときに、削除したことを Apple Inc. に通知し、本サービスと Apple の連携を解除します。このために、Apple でログインしたときに受け取るトークンを保存しています。
- 自動的な削除: 購入した写真の読み取りの利用枠が残っているアカウントは、自動的には削除しません。それ以外のアカウントは、最後に利用してから12か月がたつ30日前・7日前・前日に、登録されたメールアドレスにお知らせします。12か月がたつと、上と同じ削除を予約します（30日の猶予期間のうちにログインすると取り消されます）。「最後に利用した日」として、ログインした日と、ログイン中に操作した日を、アカウントに記録します。
- 写真の読み取りの購入記録は、アカウントを削除した後も、税の法令で帳簿などを保存する期間を満たすよう、購入した年の翌年から8年のあいだ残します。返金や、カードの不正利用の申し立てに対応するためです。残すのは、決済の番号（Stripe・Apple のもの）・購入日時・金額・取り消したかどうか・国内での購入かどうかだけで、アカウントとの結び付きとメールアドレスは消します。
- 写真の読み取りに使った量は、使うたびに、日時・量・購入した分か無料の分かを記録します。消費税の申告に使うためで、アカウントを削除した後も、アカウントと結び付けずに、使った年の翌年から8年のあいだ残します。
- 消した情報は、複製とスナップショットからも、おおむね8日のうちに消えます（削除を申し込んでから、おおむね38日）。
- 管理者による閲覧・操作の記録（→「運営者による閲覧」）は、説明の責任を果たすため、アカウントを削除した後も残します。この記録に、血圧の記録やメールアドレスは含みません。

運営者（本サービスの管理者）は、次のいずれかに当たるときに限り、利用者のアカウントの情報と記録を閲覧します。

## 安全管理のための措置

- 基本方針: 個人情報を正しく扱うため、このポリシーを定め、必要に応じて見直します。
- 組織的な措置: 個人情報を扱えるのは運営者だけです。管理者による閲覧・操作は記録に残します（→「運営者による閲覧」）。
- 人的な措置: 運営者は、個人情報を目的の外に使わず、漏らしません。
- 物理的な措置: データは、入退室が管理されたデータセンターのサーバーに保存します。運営者の手元の端末には保存しません。
- 技術的な措置:
  - 通信はすべて暗号化します（HTTPS）。
  - パスワードは復元できない形（Argon2）に変換して保存します。
  - LINE・Apple との連携を解除するためのトークンは、暗号化して保存します。
  - 利用者のデータは、そのアカウントでログインしたときだけ表示します（「運営者による閲覧」の場合を除きます）。
  - ログインの試行の回数を制限します。
- 外的環境の把握: 「アメリカ合衆国にある事業者への委託」の事業者に委託しています。アメリカ合衆国と、データを保存する国の個人情報の保護の制度を把握した上で、上の措置を講じています。
