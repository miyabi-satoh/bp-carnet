# BP Carnet

血圧の記録をつけ、グラフと印刷用のレポートにするウェブアプリ。https://bp.amiiby.com で動いている。

- 利用には、Google・LINE・Apple のアカウントか、メールアドレスでのアカウント登録が要る。
- 写真の読み取りは、写真を Google の Gemini API に送って読み取る。無料で使える額に上限があり、超えた分は購入する。
- 日本語の画面だけ。
- iPhone・iPad のアプリは、App Store に申請している。

## できること

- 血圧 (上・下)・脈拍・メモを記録する。手で打ち込むほか、血圧計の画面の写真や、手書きの記録の写真から読み取れる。
- 週・月・任意の期間で、朝・夜の平均とグラフを見る。
- 通院のときに見せる A4 横のレポートを印刷する。
- CSV で書き出す・取り込む。
- ホーム画面に追加して、アプリのように開く (PWA)。

## 使い方

ブラウザーで https://bp.amiiby.com を開き、ログインする。インストールは要らない。画面ごとの使い方は、アプリの中の「使い方」(https://bp.amiiby.com/help) にある。
